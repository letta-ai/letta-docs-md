Bring your Letta agents to Slack with Letta’s native Slack integration. Agents connected to Slack are always-on: mention them in a channel or thread and they’ll respond, using their cloud computer to do real work.

![A Letta agent responding to a mention in a Slack thread](/images/cloud-agents-slack.png)

## Setup

Visit the agent that you want to connect to Slack on [chat.letta.com](https://chat.letta.com), then click the `Connections` tab to configure a Slack app for that agent.

## Usage

Once connected, mention the agent (for example, `@Prod`) in any channel the Slack app has been added to. The agent replies in a thread, and follow-up messages in that thread continue the same conversation.
