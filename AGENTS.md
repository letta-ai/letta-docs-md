# Agent instructions

This repository is an automatically generated Markdown mirror of
[docs.letta.com](https://docs.letta.com). It is not the source of truth for the
documentation.

## Do not modify this repository

- Never commit to, push to, or open a pull request against this repository.
- Never edit files here to change the published documentation. Every
  publication force-pushes a regenerated snapshot over `main`, so hand-made
  changes are overwritten and never reach the live docs site.
- To change the documentation, open a pull request against the upstream docs
  source repository (the docs team's private repo). If you cannot locate it,
  ask the docs team in Slack instead of editing this mirror.
- If you found an error while reading this mirror, report it to the docs team
  rather than fixing it here.

## Using this repository

This mirror exists so agents can grep and read the documentation as plain
Markdown. Start with [`llms.txt`](./llms.txt), then read the relevant
`index.md` files.
